# Outils artistiques (Nin0)

- `gen_textures.py` : génère les textures procédurales originales de la bibliothèque de
  matériaux (`assets/textures/materials/`). Dépendances locales : Python 3, numpy, Pillow.
  `python3 tools/art/gen_textures.py [dossier]` puis ouvrir Godot pour l'import.

Aucune ressource externe n'est utilisée. Voir `docs/DIRECTION_ARTISTIQUE.md`.
